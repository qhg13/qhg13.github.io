This note records a lightweight workflow for building a personal homepage with GitHub Pages. The site uses HTML and CSS for the homepage, while blog posts are written in Markdown and rendered by Jekyll.

## Why GitHub Pages

GitHub Pages is suitable for personal profiles, study notes, project showcases, and public technical blogs. It works well when the site is mostly static and does not require a backend service.

## Site Structure

The homepage introduces the owner, current learning focus, selected projects, and contact links. The blog archive lists posts from the `_posts/` folder, so new writing can be added as Markdown files.

## Deployment Notes

For a user homepage, create a repository named `your-github-username.github.io`, push the files to the `main` branch, and enable GitHub Pages from the repository settings.

## Future Improvements

The site can be extended with a real avatar, project screenshots, custom domain, search, tags, and more polished long-form notes.
